# CarCast Mirror Play screenshot plan

Use real captures from a physically verified build. Do not fabricate receiver names, connection states, FPS values, or device compatibility. Do not use the Diagnostics screen as a store screenshot.

1. **Premium CarCast Home** — branded landing surface with the main Cast screen visible and no ad obscuring the primary action.
2. **Choose where to cast** — nearby device list showing the receiver card and its secure approval language. Keep the device name and connect action together.
3. **Smart TV connection / QR screen** — Browser Receiver screen with the local URL and QR code visible, using a real TV/browser test session.
4. **Casting connected** — only if the connected-state capture is safe and does not show private screen content, addresses, SAS values, or debug data. Prefer a controlled demo source.
5. **Device audio** — Browser Receiver audio control showing optional supported playback audio, without implying universal or DRM-protected audio capture.
6. **Native Receiver** — friendly receiver identity and explicit approval surface from a real compatible test device.
7. **Help / easy setup** — Help & FAQ screen showing same-network setup and recovery guidance.

For each image, capture a phone-sized portrait version and a landscape version only if the relevant surface has been physically checked in that orientation. Remove personal names, local IP addresses, QR codes tied to a real network, notifications, and third-party content before uploading.
